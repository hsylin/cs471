# LongBench source and workload decision

The bounded LongBench workload uses scientific-document QA (Qasper), government-report summarization (GovReport), and multi-document QA (HotpotQA). These task types were chosen before any performance measurement to vary document structure and expected answer length while keeping the workload small. They come from the original LongBench test split, whose published benchmark is an ACL 2024 long paper; the official repository now stores this version under `LongBench/`. This is neither LongBench-E nor LongBench-v2. [Bai et al., 2024](https://doi.org/10.18653/v1/2024.acl-long.172), [pinned official instructions](https://github.com/THUDM/LongBench/blob/2e00731f8d0bff23dc4325161044d0ed8af94c1e/LongBench/README.md)

The official task templates are preserved verbatim inside one user message and then wrapped by the pinned Qwen chat template with thinking disabled. Reference answers never enter the prompt. The original evaluator can truncate the middle of an over-limit prompt; this experiment instead rejects the entire example. It also uses the common 2,048-token output allowance, with EOS termination, rather than the original task-specific caps. Consequently, these are serving workloads, not a reproduction of the original benchmark scores. [Pinned templates](https://github.com/THUDM/LongBench/blob/2e00731f8d0bff23dc4325161044d0ed8af94c1e/LongBench/config/dataset2prompt.json), [original evaluator](https://github.com/THUDM/LongBench/blob/2e00731f8d0bff23dc4325161044d0ed8af94c1e/LongBench/pred.py)

The data licenses come from the upstream authors' sources, rather than treating the LongBench code's MIT license as a blanket license for all underlying text. The pinned Qasper card identifies CC BY 4.0; the GovReport project's own source page identifies CC BY 4.0; HotpotQA's project identifies CC BY-SA 4.0. Preserve the respective attribution and terms with derived material. Raw text and candidates remain outside Git. [Qasper license](https://huggingface.co/datasets/allenai/qasper/blob/fdc9d8214fbab5dd782958601db4d678e6934a54/README.md), [GovReport license](https://github.com/gov-report-data/gov-report-data.github.io/blob/8dfd043210c02f5b425cf3e04667a7488a3f7237/index.md), [HotpotQA license](https://github.com/hotpotqa/hotpot/blob/3635853403a8735609ee997664e1528f4480762a/README.md)

FreeBalance's August 2026 preprint includes all three tasks in Table 1, but its measurements concern prefill at batch size 16 and input length 8K on eight A800 GPUs. Its Qwen checkpoint is Qwen3-30B-A3B-Instruct-2507. Our full autoregressive requests, H100 topology, base Qwen3-30B-A3B checkpoint, native online EPLB, and natural input lengths differ. The dataset overlap supports a workload connection; it does not make this an exact reproduction or validate a response-latency claim. [FreeBalance v1, section 4](https://arxiv.org/html/2608.14205v1#S4)

Preparation read all 200 records in each chosen original test subset. Three GovReport prompts exceeded the 32,768-token context bound when reserving 2,048 output tokens and were rejected without shortening. Every accepted prompt exceeds 512 tokens. These are completed CPU data checks, not GPU measurements. The accompanying manifest records all source pins, hashes, rejected IDs, actual token lengths, and environment versions. Multiple Qasper questions share a paper; `group_id` hashes the complete normalized context, and downstream selection must retain at most one request per group before separating pilot and final samples. The pool contains 597 candidates, not a frozen final allocation.
