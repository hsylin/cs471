# Instructor-feedback supplement evidence

The [report](../../docs/instructor-feedback-results.md) and [reproduction guide](../../docs/instructor-supplement-reproduction.md) describe the scope and commands.

- `arrivals-v1/`: complete calibration and evaluation raw records, immutable calendars, physical assignments, independent raw/archive audits, descriptive summaries, all-cell report and monochrome figure.
- `architecture-v1/`: independent architectural work reconstruction, original pre-probe note, updated post-probe note and successful CPU reproduction.
- `counters-unavailable-v1/`: complete failed Nsight Compute permission probe and independent outcome audit; no expert hardware counters were captured.
- `execution-ledger.json`: source pins, scheduler history, exact counts and interpretation boundaries.

Compressed JSONL files preserve the original bytes exactly. Their decompressed hashes bind the evaluation calendars. Repeated input artifacts are retained by phase. Old studies and their acceptance decisions are unchanged; the arrival results are descriptive on reused development inputs.
