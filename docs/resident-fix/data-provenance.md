# Fresh inputs for the resident fast-path comparison

The selection contains 704 fresh source documents in 22 groups of 32 documents. GSM8K and WildChat each contribute two pilot and eight final groups. MBPP contributes one pilot and one final group as a separate descriptive sentinel. After exclusion of all earlier selections and captured prefixes, only 73 eligible MBPP tasks remain in the pinned source frame; 64 are selected. The reduced MBPP allocation was fixed from this source-capacity check before capture or performance measurement. MBPP is not a third population stratum in the main inference.

The input origins and their terms are unchanged from the previous comparison: [GSM8K test questions](https://github.com/openai/grade-school-math/blob/3101c7d5072418e28b9008a6636bde82a006892c/grade_school_math/data/test.jsonl), under its repository's MIT license; [MBPP task descriptions](https://github.com/google-research/google-research/blob/0eebfd403ba438bfd14cb70b9b24a7745c997083/mbpp/mbpp.jsonl), under the repository's CC BY 4.0 dataset terms; and the [pinned WildChat first shard](https://huggingface.co/datasets/allenai/WildChat/blob/f66566ceaaeb619dd98ffb0f3bf3ce1f86775ac4/data/train-00000-of-00006.parquet), with its recorded ODC-By database terms. That database license does not establish separate rights over every conversation's contents. The public source manifest records exact downloaded-byte hashes and source IDs. Full selected text and token IDs are held in the private capture manifest; the public manifest omits those fields. Neither hashes nor eventual token records are a claim of anonymization.

Selection uses only question/task/first-user text, no answers, code solutions or generated continuations. The WildChat frame remains the first 8,192 rows of the pinned shard, requiring English, a non-toxic conversation and first user turn, and nonempty first-user text. Every source must have at least eight tokenizer tokens. At most the first 512 tokens are captured, without a chat template or added special tokens. The tokenizer belongs to Qwen3-30B-A3B revision `ad44e777bcd18fa416d9da3bd8f70d33ebb85d39`; its JSON SHA256 is `aeb13307a71acd8fe81861d94ad54ab689df773318809eed3cbe794b4492dae4`. Prefix decoding during selection uses tokenizers 0.23.3.

The exclusion union contains 2,695 previously selected source documents: all three earlier generalization selections, including superseded and unused held-out selections (1,927 unique documents), plus all 768 stock-comparison documents. It also includes 56 source documents from 28 older two-document capture banks. Identifier matches, normalized exact text, and near duplicates are excluded before the new split. Normalization uses Unicode NFKC, case folding and collapsed whitespace. Near duplication is Jaccard similarity of at least 0.8 over sets of five regex-word/punctuation shingles, checked on full prompt text and model-visible captured prefixes. Historical long sources contribute their actual first 2,048-token view, the common first-512-token view, and a normalized whole-source exact hash. These checks do not establish absence of shorter shared phrases, semantic paraphrases or model-pretraining overlap.

The resulting eligible pools contain 423 GSM8K, 2,048 WildChat and 73 MBPP documents. Seed 471701 ranks source identity and text hash; no routing demand or performance observation enters selection. The canonical private source-manifest hash is `483864373cef39ff7050e463f135fccb8941988b3ed6b75e8d880e319e332df6`, linked by `results/resident-fix/content-v1/source-manifest.json`. New identifiers begin with `fix-`, and the capture schema is `resident_fix_sources_v1`, so the earlier study's capture interface cannot silently accept this selection.

The new capture wrapper retains the earlier authentic causal-prefill boundary mechanism: the pinned BF16 embedding, layer-0 attention, normalization and router execute separately for every prompt. It records post-attention expert inputs, source token positions, native router output and exact tensor/implementation hashes, with boundary, router and BF16-roundtrip checks. The measured comparison consumes captured hidden vectors only; its actual vLLM layer recomputes its own gate, top-k and combining weights. Captured HuggingFace routing remains provenance. Capture validity and timed-runtime numerical validity are separate obligations. At source-selection time, the planned banks contain 1,784–2,151 GSM8K records, 2,387–6,712 WildChat records and 494/516 MBPP records. The constructed 4,096-job trials necessarily reuse these bounded token records; they are not natural request sessions. Exact per-job source-index and reuse artifacts must accompany execution.

Arrival selection uses the original [Azure code](https://github.com/Azure/AzurePublicDataset/releases/download/dataset-llm-2024/AzureLLMInferenceTrace_code_1week.csv) and [conversation](https://github.com/Azure/AzurePublicDataset/releases/download/dataset-llm-2024/AzureLLMInferenceTrace_conv_1week.csv) CSVs, subject to the [recorded CC-BY attribution instructions](https://github.com/Azure/AzurePublicDataset/blob/215becdacba1ce682c7368642ce97d5a332de7a6/AzureLLMInferenceDataset2024.md). Both complete files are scanned: 16,803,695 code rows and 27,303,999 conversation rows. Each candidate has 4,096 releases and one following boundary row; day boundaries are not crossed. All 92 older selected intervals and all 48 stock-comparison intervals, including boundary rows, are excluded. Among the 4,096 code candidate bins, 76 overlap prior intervals; among 6,660 conversation bins, 71 overlap. Seed 471702 chooses bounded hash-ranked candidates within each source date, without selection on burstiness or execution time. A selected nonpositive horizon or terminal gap fails rather than causing replacement.
