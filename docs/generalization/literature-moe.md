# MoE systems evidence for generalization

The combined dispatcher addresses an established systems problem: token balance, expert activation, memory traffic and completed latency need not improve together. Its credible contribution is the implementation and measured cost of preserving the same logical routes while changing physical replica assignment and avoiding unnecessary native update work. The general principle is already present in prior systems. MegaScale-Infer explicitly models an expert's minimum execution cost with a floor rather than a purely linear token count, while the METRO preprint directly minimizes activated experts through physical dispatch and a different global-information transport. A generalization claim therefore needs evidence that this particular implementation improves completed execution across relevant regimes; it should not claim to introduce expert-activation-aware balancing. [MegaScale-Infer, SIGCOMM 2025](https://doi.org/10.1145/3718958.3750506); [METRO, preprint](https://arxiv.org/abs/2512.09277v1).

The useful boundary is between logical routing and physical execution. GShard changes the model's top-2 selection, capacity and balancing rules, whereas Lancet carefully passes capacity state between partitions to retain exactly the original token assignment and dropping behavior. Occult offers both an exact physical communication path and a distinct pruning path that changes selected experts and requires quality evaluation. Pre-gated MoE changes gating to enable lookahead and fine-tunes the model. These are different interventions, even when all are called MoE acceleration. The present study belongs to exact physical execution only if every selected logical expert and combining weight is preserved, every dispatched copy holds the correct weights, and numerical comparisons cover both ordinary and adversarial cases. Output tolerance is a correctness criterion, not permission to change the router. [GShard, ICLR 2021](https://openreview.net/forum?id=qrwe7XHTmYb); [Lancet, MLSys 2024](https://proceedings.mlsys.org/paper_files/paper/2024/hash/339caf45a6fa281cae8adc6465343464-Abstract-Conference.html); [Occult, ICML 2025](https://proceedings.mlr.press/v267/luo25f.html); [Pre-gated MoE, ISCA 2024](https://doi.org/10.1109/ISCA59077.2024.00078).

A second boundary separates resident dispatch from changing the memory and communication architecture. DeepSpeed-MoE jointly optimizes parallelism, sparse gating kernels and hierarchical all-to-all. Janus moves experts toward training data; Fiddler chooses CPU computation instead of repeatedly transferring cold expert weights; MoE-Lightning coordinates CPU attention, GPU computation and offloading under memory constraints. Their gains can be substantial, but they do not establish that resident-copy assignment alone helps. A two-rank harness with replicated input and output allreduce does not include the token dispatch/combine traffic, attention, KV cache or dynamic request batching of those systems. Results from that harness can support a layer-service claim; full-serving claims require the omitted path to be implemented and measured. [DeepSpeed-MoE, ICML 2022](https://proceedings.mlr.press/v162/rajbhandari22a.html); [Janus, SIGCOMM 2023](https://doi.org/10.1145/3603269.3604869); [Fiddler, ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/8cd1ce03ea58b3d7dfd809e4d42f08ea-Abstract-Conference.html); [MoE-Lightning, ASPLOS 2025](https://doi.org/10.1145/3669940.3707267).

The closest kernel papers make expert shape and token-group size central to external validity. MegaBlocks avoids global expert-capacity padding by rounding each expert's group to a block, but its training workloads have much larger expert groups than the present small-batch inference setting. SonicMoE separately reduces activation IO and changes token assignment through rounding; only its exact-routing component is a candidate control here. FlashMoE and COMET reduce CPU scheduling costs and overlap communication using device-side or fused execution. COMET's small-group discussion is particularly relevant to a no-op shortcut, but its intervention also changes communication and grouped-GEMM scheduling. FlashMoE's reported comparison additionally uses different precisions for its implementation and baselines, so its headline speedup cannot calibrate an expected BF16 effect in this study. [MegaBlocks, MLSys 2023](https://proceedings.mlsys.org/paper_files/paper/2023/hash/5a54f79333768effe7e8927bcccffe40-Abstract-mlsys2023.html); [SonicMoE, ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/6ed5bf446f59e2c6646d23058c86424b-Abstract-Conference.html); [FlashMoE, NeurIPS 2025](https://doi.org/10.52202/085713-3368); [COMET, MLSys 2025](https://proceedings.mlsys.org/paper_files/paper/2025/hash/e27ea0cd50b798ff8942caf9203f0992-Abstract-Conference.html).

Work counts are useful mechanism measurements but are insufficient latency models. Lancet can increase total computation through partitioning while reducing elapsed time through overlap. COMET preserves grouped-GEMM efficiency by choosing a profiled compute/communication resource split, rather than assuming that fewer operations always win. The TEMPO preprint makes the limitation explicit: memory-bound expert activation and tile-rounded compute can coexist in a single batch, and its reported negative cases include configurations where a static baseline wins or communication dominates. Consequently, a generalization experiment should record activated physical experts, token distribution, padding proxies, mapper cost and rank completion times while retaining completed elapsed time as the outcome. Without hardware counters, reduced activation is consistent with reduced weight traffic but is not a measured HBM-bandwidth result. [Lancet, §7.1](https://arxiv.org/pdf/2404.19429); [COMET, §§3.2 and 5](https://arxiv.org/pdf/2502.19811); [TEMPO v2, preprint](https://arxiv.org/abs/2608.13057v2).

Temporal adaptation is already a cost-sensitive design problem in the conference literature. SmartMoE uses a predicted-gain threshold, prefers placements close to the current mapping in ties, and discusses the trade-off between search overhead and stale decisions. Tutel avoids parameter re-layout when switching compatible execution modes. LAER-MoE exploits the particular re-sharding opportunities of training to incorporate expert re-layout; this does not make migration free in inference. The Gimbal and FreeBalance preprints extend this history with migration-stability terms and an explicit limit on transfers that can fit within a prediction/overlap window. A new gate based only on two nearby routing windows therefore requires a distinct predictive hypothesis and charged future benefit. Low distributional change alone does not establish positive migration payback. [SmartMoE, §§6.2 and 7.4, ATC 2023](https://www.usenix.org/system/files/atc23-zhai.pdf); [Tutel, MLSys 2023](https://proceedings.mlsys.org/paper_files/paper/2023/hash/5616d34cf8ff73942cfd5aa922842556-Abstract-mlsys2023.html); [LAER-MoE, ASPLOS 2026](https://doi.org/10.1145/3779212.3790180); [Gimbal, preprint](https://arxiv.org/abs/2606.15177v1); [FreeBalance, preprint](https://arxiv.org/abs/2608.14205v1).

The best transferable evaluation practice is a common implementation with explicit component controls. Lancet compares against unmodified RAF to separate its scheduling decisions from compiler differences. COMET keeps attention implementation fixed. LAER-MoE includes a baseline that already has its communication optimizations, so balancing is tested beyond those optimizations. Lina separates unprofiled end-to-end measurements from profiler runs, rather than treating instrumented execution as the primary result. For the current composition, native, shortcut and combined arms isolate the incremental benefit of online dispatch after the shortcut; they do not identify an interaction or synergy without an online-only arm. This three-arm contrast is sufficient for the narrower incremental claim and should remain fixed across new workloads. [Lina, §7.1, ATC 2023](https://www.usenix.org/system/files/atc23-li-jiamin.pdf); [Lancet, §7](https://arxiv.org/pdf/2404.19429); [COMET, §5](https://arxiv.org/pdf/2502.19811); [LAER-MoE, §5](https://arxiv.org/pdf/2602.11686).

Negative regimes should be selected before measurement. LocMoE reports that locality loses value at a larger device scale when local experts are unavailable. Fiddler's CPU/GPU balance changes with hardware and batch shape, while COMET changes its preferred resource split with token count and parallelism. Within the authorized one-layer scope, these observations support prespecified new content captures that vary the observed routing distribution through the same pinned layer. They do not justify choosing content because it produces favorable pilot speedups. The bounded follow-up should separate pilot choices from final payload sources and keep the checkpoint, layer, B128 main shape, precision, weights, placement budget and transport fixed within each paired comparison. Other layers, expert widths and model architectures remain untested external-validity boundaries; any larger-batch check must be a separately declared diagnostic. [LocMoE, IJCAI 2024](https://doi.org/10.24963/ijcai.2024/705); [Fiddler, §4](https://arxiv.org/pdf/2402.07033); [COMET, §§3.2 and 5.4](https://arxiv.org/pdf/2502.19811).

Generalization also requires a defensible experimental unit. Most papers in this subset report iteration averages, model/configuration sweeps or benchmark batches; the inspected sections do not establish independent workload-population confidence intervals. Their technical repetitions should not be converted into an assumed sample size for a new study. Fresh arrival seeds test calendar variation conditional on the payload bank. New document captures test a further source dimension, but many constructed jobs drawn from one bank remain dependent. Claims should therefore distinguish fresh schedules, fresh source documents, new layers and new model architectures. A block-level analysis can quantify the prespecified variation actually sampled; it cannot convert one hardware allocation or a small fixed source corpus into a population-wide serving guarantee.

Artifact availability is uneven and must not be conflated with reproduction. Ten of the counted papers have a paper appendix or a presently inspected public artifact covering methods or execution setup: Tutel, MegaBlocks, SmartMoE, Fiddler, Pre-gated MoE, FlashMoE, Occult, SonicMoE, LAER-MoE and COMET. Current repository commits and available files are recorded in the source inventory; none was benchmarked for this review. Libra is a verified ICLR 2026 paper with a substantial public SGLang-based artifact, but its final PDF could not be retrieved, so its README was not promoted into a full-paper methods record. The NeurIPS 2024 paper *Toward Efficient Inference for Mixture of Experts* has a placeholder repository at the inspected commit; an older differently titled manuscript was not substituted for its final paper. These access limits reduce what can be claimed about their experiments, not their importance as prior art. [Libra proceedings](https://proceedings.iclr.cc/paper_files/paper/2026/hash/9ff1ac9a659085fed0735362cafe5e53-Abstract-Conference.html); [Libra artifact](https://github.com/SNU-ARC/Libra); [Toward Efficient Inference proceedings](https://papers.nips.cc/paper_files/paper/2024/hash/98bf3b8505c611ac21055dd9d355c66e-Abstract-Conference.html); [artifact placeholder](https://github.com/hyhuang00/moe_inference).

The resulting recommendation is a bounded test of portability, not a new balancing mechanism selected from the final results. Preserve the exact-routing three-arm implementation and the same pinned Qwen layer, use prespecified authentic captures from distinct sources, construct and disclose the B128 job grouping, and measure all overhead through rank completion. State the boundary in advance: improvement may disappear when replica choices vanish, mapper overhead dominates, large expert groups become compute-bound, or the transport path changes. A successful result would show that the measured incremental benefit persists across those declared captures and arrival conditions; an unsuccessful one would establish where this implementation stops helping. Neither outcome by itself would establish whole-model autoregressive serving performance.
