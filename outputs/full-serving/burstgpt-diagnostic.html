Descriptive fixed-order, single-block pilots only. Datasets and stages are kept separate. No independent-run confidence interval or final speedup claim is available. Requests are not independent experimental repetitions. A complete report means the input/calendar and failure gates passed; it does not prove numerical or committed-state correctness.

OFF means native vLLM with EPLB disabled; ON means native vLLM with EPLB enabled. This comparison does not test the custom resident dispatcher. Response time runs from the scheduled arrival to stream completion; TTFT runs from client submission to the first nonempty content. Completed elapsed time runs from the shared arrival epoch through final request completion; it excludes server startup and earlier phases. Output tokens/s uses actual generated tokens divided by completed elapsed time.
